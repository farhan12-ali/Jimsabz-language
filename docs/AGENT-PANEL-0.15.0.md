# Code Madadgar panel — Studio 0.15.0

This update applies only the agent portion of the supplied neon workspace
reference. The editor, compiler visualization and separate Run window retain
their existing layout and behavior. The reference does not add other programming
languages, a cloud model provider, or a new online AI connection to this project.

The new panel has a compact robot profile, a neon blue/purple border, a welcome
bubble and six actions: Write a program, Build a game, Explain concepts, Create
a project, Fix my code and General question. The bottom composer has Code,
Search, Attach and Voice controls. Its status says Ready · Local or Working
locally, reflecting the actual included local engine.

Write a program and General question focus the existing composer without
replacing typed text. Build a game opens supported starters, Explain concepts
opens Learning and Create a project opens the existing project dialog. Fix my
code uses the existing local repair request. Search opens bundled documentation.
The gear reveals the retained Chat/Tools/Projects/Learning views, voice-language
chooser, about information, notes, activity, undo and retry. The trash icon opens
history and its explicit clearing control; clicking the icon alone deletes
nothing. Code cards, Copy code, review/apply/reject and attachments are retained.
