# 3. LANGUAGE SYNTAX AND KEYWORDS

| Jimsabz type | Purpose |
|---|---|

- Statements terminate automatically at newlines.
- Semicolons are used only where the language requires them, such as the documented `gin(init; condition; step)` loop header.
- Blocks use `{}`.

Recognize documented imports:

- `kharna audio`
- `kharna hisab`
- `kharna waqt`
