# Sindhi mentor recordings

Optional authentic voice recordings can be placed here:

- `sahee_na_tu_kari.wav` — the compilation error cue.
- `haan_sahee_aa_na.wav` — the successful build cue.

Use recordings you have permission to distribute. These recordings are not included. Without them, Studio sends the Roman Sindhi phrases to the installed Windows SAPI voice; pronunciation depends on that voice and is not an authentic Sindhi recording. Mentor can be muted in the top bar.
